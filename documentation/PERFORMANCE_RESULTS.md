# Performance results

Generated by `tests/run_benchmark.sh` (`make bench`) on our development
laptop: 16 logical cores, WSL 2 on Windows, gcc `-O2 -fopenmp`. The model
files were read from a OneDrive folder through `/mnt/c` (this only affects
the load time). Rerun `make bench` to regenerate this file on another
machine. It then also records the CPU model, RAM and date.

- Workload: 32 prompt tokens + 64 generated tokens (greedy),
  KV cache allocated for 96 positions; median of 3 runs.
